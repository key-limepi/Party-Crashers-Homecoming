# PARTY CRASHERS: HOMECOMING

**Party Crashers; Done Right!**

Party Crashers: Homecoming is a 2D asymmetrical multiplayer game I'm making.

The main idea is pretty simple. You have Survivors and a Killer, and everyone has their own characters, abilities, and stuff to work with.

## The Game

The game goes through a few different phases during a match.

### Lobby

Everyone starts in the lobby.

Players can join, talk, and get ready for the next match.

### Intermission

Once the lobby is ready, a 30 second intermission starts.

This happens before every match, so players aren't immediately thrown into character select as soon as the lobby fills.

### Character Select

After the intermission, everyone gets to choose their character.

You can look through the available characters and pick who you want to play.

Once everyone has picked, the match starts.

### The Match

The Killer's goal is to eliminate the Survivors.

The Survivors have to stay alive and use their characters, abilities, and the map to their advantage.

Every character is supposed to play differently, so choosing who you play actually matters.

### Last Man Standing

If the match gets down to one Survivor and the Killer, LMS starts.

It's just a 1v1.

There isn't a timer for LMS. The fight keeps going until either the Survivor or the Killer dies.

### Match End

Once the match is over, everyone goes back to the lobby and the whole thing starts again.

If the match ends before LMS happens, it just skips that part and goes back to the lobby.

## How to Run

Clone the repository:

```bash
git clone https://github.com/key-limepi/Party-Crashers-Homecoming.git
cd Party-Crashers-Homecoming
```

Then run:

```bash
python server.py
```

If you're on Windows, you can also use `start-server.bat`.

After the server is running, open `index.html`.

## Controls

### Gameplay

* Arrow Keys: Move
* Enter: Chat
* F12: Debug Menu

### Character Select

* Arrow Keys: Browse characters
* Enter: Pick a character
